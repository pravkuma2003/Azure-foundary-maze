Phase 22 - Automated Build Trigger

GitHub changes automatically create candidate images; Foundry rollout stays manual.

Controlled Delivery Flow

Mac

Edit role-agent code and push to GitHub.

GitHub

Commit on main fires the source trigger.

ACR Task

Pulls hosted/maze-role-agents and builds automatically.

Candidate Image

Publishes phase22-latest plus a run-specific tag.

Manual Gate

Operator chooses when to promote the candidate image.

Foundry

Docker-backed agents run only the promoted image.

The automated trigger changes the artifact pipeline, not the live agent runtime.
