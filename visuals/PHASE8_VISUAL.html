WebUI Flow

1. Browser

Loads Azure-hosted HTML/JS playback UI.

2. Function API

/api/run receives the user click.

3. Identity

Managed identity gets the Azure AI token server-side.

4. Agent

Calls the Foundry hosted maze endpoint.

5. Playback

Trace JSON renders play/pause/replay timeline.
