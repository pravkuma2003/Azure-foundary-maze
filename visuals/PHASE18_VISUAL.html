Phase 18 - Human Feedback Telemetry

Capture simple per-worker human feedback without changing agent behavior yet.

Feedback Flow

Learner

Chooses Thumbs Up or Thumbs Down next to Maze A or Maze B.

Azure WebUI

Posts /api/feedback with run id, maze id, worker, rating, and note.

App Insights

Stores a structured MazeFeedback trace for later Log Analytics reports.

Team Memory

Appends the same feedback to feedback.events when a run id exists.

Learning Boundary

Feedback is observed and recorded only. Worker prompts, routes, and decisions are not changed in this phase.
