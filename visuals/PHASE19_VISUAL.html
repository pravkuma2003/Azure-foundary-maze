Phase 19 - Docker Packaging Boundary

Build the same hosted-agent code into an Azure Container Registry image without requiring local Docker.

Option B Flow

Mac / Git

Code is edited, committed, and pushed as the source of truth.

Dockerfile

Defines Python 3.13, requirements install, app files, and startup.

ACR Build

az acr build builds the image inside Azure.

ACR Image

Versioned image tag stores the packaged agent runtime.

Foundry Runtime

Later phase can point hosted agents at the image.

Learning Boundary

The agent behavior does not change. Docker controls packaging, dependency restore, and runtime reproducibility.
