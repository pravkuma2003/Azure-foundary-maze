Phase 24 - Post-Run Evaluation Agent

A separate hosted Reviewer evaluates completed maze runs from Team Memory and feedback.

Runtime Flow

WebUI

Coordinates the learner flow and stores durable Team Memory.

Analyst Agent

Generates Maze A and Maze B, then assigns Workers.

Worker Agent A

Solves Maze A independently.

Worker Agent B

Solves Maze B independently.

Team Memory

Stores maze layouts, Worker outcomes, moves, guardrails, and thumbs feedback.

Reviewer Agent

Reads completed Team Memory, scores quality, and writes review findings.

The Reviewer is evaluation-only. It does not choose moves or trigger retries in this phase.

Review Artifact

Inputs
  • Worker outcomes
  • LLM call counts
  • guardrail corrections
  • durable Team Memory state
  • thumbs feedback
Outputs
  • score and threshold
  • approved or needs review
  • targeted findings
  • recommended retry target
  • human review gate
