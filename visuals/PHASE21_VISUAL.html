Phase 21 - GitHub Source to ACR Image Build

Build the hosted role-agent image from GitHub, then run that image in Foundry.

Deployment Flow

Mac

Edit code, commit, and push. The Mac does not build the container.

GitHub

Source of truth for the build ref: branch, tag, or commit.

ACR Build

ACR pulls hosted/maze-role-agents and builds the image.

ACR Image

maze-role-agent:phase21-github-main becomes the deployable runtime package.

Foundry

Docker-backed hosted agents run the Git-built image.

The application logic stays the same; the source of the container build moves from local filesystem to GitHub.

Learning Boundary

This is still an operator-triggered build, not an automatic CI/CD pipeline. The next lesson can add a GitHub trigger or release workflow.
