Phase 9 - Maze Tool Boundary

Boundary Flow

1. Worker Agent

Reasoning owner

Chooses what operation it needs: inspect or move.

2. MazeTool Program

Callable boundary

Receives typed request fields and returns typed result fields.

3. Maze Engine

Rule owner

Knows grid bounds, walls, legal moves, and validation.

4. Later Phase

Deployment split

The same contract can become an Azure Function or hosted tool later.
